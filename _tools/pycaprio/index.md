[Pycaprio][1] is a Python client for the INCEpTION remote API. Use it to work with projects on an
INCEpTION server from your own Python code, for example to create projects.

To connect, you need the address of your INCEpTION server and a user with the `REMOTE` role.
Installation instructions and usage examples are in the [repository][1] and the [documentation][2].

[1]: https://github.com/inception-project/pycaprio
[2]: https://pycaprio.readthedocs.io
