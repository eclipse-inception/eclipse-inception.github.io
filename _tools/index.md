Tools from the wider INCEpTION ecosystem help you convert data, analyze your annotation projects and
provide additional recommenders.

The tools listed here are provided outside the Eclipse Foundation and are not part of the Eclipse
INCEpTION project.

* [CORLINCEpTION converter]({{ site.url }}/tools/corlinception/): convert standard XML to and from INCEpTION
* [DKPro Cassis]({{ site.url }}/tools/cassis/): work with UIMA CAS data in Python
* [External Recommender for INCEpTION]({{ site.url }}/tools/external-recommender/): run your own recommenders using Python
* [INCEpTALYTICS]({{ site.url }}/tools/inceptalytics/): analyze INCEpTION annotation projects
* [Pycaprio]({{ site.url }}/tools/pycaprio/): Python client for the INCEpTION remote API
* [Reporting Dashboard for INCEpTION]({{ site.url }}/tools/reporting-dashboard/): track and visualize the progress of your projects
* [xMEN Recommender for INCEpTION]({{ site.url }}/tools/xmen/): cross-lingual medical entity linking

If you would rather write your own code, have a look at the [code examples]({{ site.url }}/code-examples/).
