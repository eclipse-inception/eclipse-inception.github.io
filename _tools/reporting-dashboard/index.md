The [Reporting Dashboard for INCEpTION][1] helps you track and visualize the progress of your INCEpTION
projects. It runs in your browser, visualizes project metrics and annotation types, and exports
progress reports.

It requires Python 3.11 or higher and is installed and started with:

```
pip install -U inception-reports
inception_reports
```

A Docker image is also available. See the repository for details.

[1]: https://github.com/inception-project/inception-reporting-dashboard
