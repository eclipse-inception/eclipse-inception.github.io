[DKPro Cassis][1] is a pure-Python implementation of the UIMA Common Analysis System (CAS). It can create
and manipulate annotated documents and their type systems, and load and save them in the CAS XMI and
CAS JSON formats.

This makes it useful for preparing data to import into INCEpTION and for processing annotations you
have exported from it, for example together with Python NLP and machine learning libraries.

See the [documentation][2] for details.

[1]: https://github.com/dkpro/dkpro-cassis
[2]: https://cassis.readthedocs.io
