# Contributing to the Eclipse INCEpTION website

This repository holds the source of the project website, https://eclipse-inception.github.io.
It is a Jekyll site; the [README](README.md) explains how to build and preview it locally.

Contributions are welcome as pull requests. As for all Eclipse projects, you need to sign the
[Eclipse Contributor Agreement](https://www.eclipse.org/legal/eca/) first.

Everything else (Terms of Use, Developer Certificate of Origin, use of generative AI, contact)
is the same as for the application and is described in its contribution guide:

* https://github.com/eclipse-inception/inception/blob/main/CONTRIBUTING.md
